# SysCilia v1 source

`source/scgs.v1.tsv` is the public SysCilia Gold Standard version 1.0
(GS version 4.0), dated 2013-05-22 and based on Ensembl release 71.

The file is preserved without modification. Its header documents the authors,
release, column meanings, supporting publications, ciliome evidence, and
curated protein-localization field used by this analysis.
